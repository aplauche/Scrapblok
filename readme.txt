Scrapblok 

== Description ==

This block allows you to build collage style layouts within WordPress.

== Installation ==

1. Upload the plugin files to the `/wp-content/plugins/scrapblok` directory, or install the plugin through the WordPress plugins screen directly.
2. Activate the plugin through the 'Plugins' screen in WordPress


== Frequently Asked Questions ==

= What kinds of sites can I use this on? =

This block can do all kinds of more complex layouts that require careful absolute positioning of elements
